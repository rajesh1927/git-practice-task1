# DevOps Notes App

A small project created to practice Git and GitHub version control.

## Project Objective

This project demonstrates basic Git operations including:

* Git repository initialization
* Creating commits
* Creating branches
* Switching branches
* Merging branches
* Resolving merge conflicts
* Maintaining a clear commit history
* Pushing a project to GitHub

## Project Structure

```text
devops-notes-app/
├── index.html
├── notes.txt
└── README.md
```

## Technologies

* HTML
* Git
* GitHub

## Git Commands Practiced

```bash
git init
git add
git commit
git branch
git checkout
git merge
git status
git log
git push
```

## Branches

The project uses feature branches to practice development workflows.

Example:

```text
main
 └── feature/add-aws
 └── feature/update-title
```

## Merge Conflict

A merge conflict was intentionally created by modifying the same line in `index.html` on two different branches.

The conflict was manually resolved and committed to the main branch.

## Learning Outcome

This project helped me understand how Git manages versions, branches, merges, conflicts, and collaboration through GitHub.
